# Phone install: the questions, in full

| Header | Question | Options (with the explanation to show) |
|---|---|---|
| `App name` | What should the app be called on the home screen? | **"<name found>" (Recommended)**: the name under the icon and in the install steps · **A shorter label**: for names over 12 characters, which iPhone cuts off (type it) |
| `Icon` | What should the app icon be made from? | **The logo I found (Recommended)**: placed on a plain or gradient background in every size · **A finished square icon**: used as it is (512 px or larger) · **A simple lettered icon**: the first letter on the brand colour, until a logo exists |
| `Colours` | Which colour should the browser and status bar use? | **<brand / page colour found> (Recommended)**: matches the app's top bar · **White**: a neutral light bar · **Dark, see-through bar**: for dark or full-bleed screens on iPhone (`--status-bar black-translucent`) |
| `On a phone` | When someone opens the link on a phone, what should they see? | **The first screen, full screen (Recommended)**: like the real app; the desktop still shows the presenter frame · **The presenter frame on phones too**: a demo inside a phone picture (`--no-redirect`) |
| `Install tip` | How should people learn they can install it? | **A banner on the start screen (Recommended)**: appears once, can be dismissed for a week · **Banner and an "Install as app" row** on a settings or profile screen · **No prompt**: it is still installable from the browser menu |
