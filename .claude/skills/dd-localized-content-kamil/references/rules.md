# Localized content: rules (Malaysia)

| Thing | Format | Example |
|---|---|---|
| Price | RM, no space, 2 decimals; thousands with a comma | RM12.90 · RM1,299.00 |
| Date | Day, short month, year (en-GB) | 24 Nov 2026 · short: 24 Nov |
| Time | 12-hour, lower-case am/pm | 3:45 pm |
| Phone | +60, then the mobile prefix without 0 | +60 12-345 6789 · +60 11-2345 6789 |
| Address | Unit, street, area, postcode city | A-15-3, Jalan Kiara 3, Mont Kiara, 50480 Kuala Lumpur |
| Malay names | Given name + bin/binti + father's name; short form given + father | Aina binti Rosli → "Aina Rosli" |
| Chinese names | Surname first, or English name + surname | Tan Wei Jie · Michelle Lim |
| Indian names | Given name + a/l (a/p) + father's name; short form given + father | Priya a/p Krishnan → "Priya Krishnan" |
| Car plate | State letter(s) + letters + number | WXY 1234 |

## Never

- Lorem ipsum, "John Doe", "Jane Smith", "User name", "Product name", "Item 1".
- $ or USD prices, US addresses or ZIP codes, 555 numbers, MM/DD dates.
- Real public figures (politicians, celebrities), real companies' logos as content, real IC (MyKad) numbers, bank account numbers. If an IC must show, use an obviously masked form: `9•••••-••-••12`.
- Names that don't match the place or price (a RM450 room in Mont Kiara).

## Plausible ranges (2026)

Food stall meal RM8-16 · kopitiam drink RM2-5 · café latte RM12-18 · Grab ride in KL RM9-35 · room rent RM450-1,200 · condo rent RM1,500-4,500 · fresh-grad salary RM3,000-4,500 · smartphone RM899-5,299.
