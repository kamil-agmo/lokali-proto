# Localized content

**Made by Kamil**

Screens are judged by their content: "Aina Rosli ordered 2x Nasi lemak ayam goreng · RM19.80" sells a prototype; "John Doe · $9.99" breaks it. A script makes the content from a Malaysian data set, so Claude never has to load the lists (few tokens), and a fixed seed keeps every person, price and order the same across screens.

**Make things make sense:** everything this skill produces must make sense to a first-time viewer; the last step checks it.

**Be brief:** questions, summaries and reports stay short: the answer first, one line per point, detail only when asked.

## Step 0: ask first

Skip what `DESIGN.md` "## Content" already answers. AskUserQuestion, recommended first, every option explained:

1. **Market:** Malaysia (recommended; the data set) · Other (name it: Claude writes the content by hand with the same rules).
2. **Language:** English with Malay for local terms (recommended: "Nasi lemak", "Jalan Telawi 3") · Bahasa Melayu · Mixed, as people really type (chat and reviews only).
3. **Names:** Malaysian mix (recommended: Malay, Chinese, Indian) · Add East Malaysian (Sabah, Sarawak briefs) · One group (when the brief says so).

Then `python3 <skill>/scripts/content.py section --project <project>` (flags: `--market`, `--language`, `--mix`).

## Make content

```bash
python3 <skill>/scripts/content.py gen people --n 6 --seed 1          # name, full name, username, email, +60 phone
python3 <skill>/scripts/content.py gen orders --n 5 --seed 2          # id, shop, items, RM total, date, status
python3 <skill>/scripts/content.py gen products --cat food --n 8      # food, drinks, grocery, fashion, electronics, services
python3 <skill>/scripts/content.py gen addresses|phones|messages|dates|plates|businesses --n 4
python3 <skill>/scripts/content.py gen places --n 8 --cat "Kuala Lumpur" --format json   # map points: name, address, lat, lng (dd-map-kamil)
```

One line per record; `--format json` or `csv` for a data file. Use one seed per kind for the whole prototype (record it in `DESIGN.md`), so screens agree. Rules: `references/rules.md` (formats, what never to use).

## Check

```bash
python3 <skill>/scripts/content.py scan --project <project>   # Lorem ipsum, John Doe, $ prices, 123 Main St, example.com, 555 numbers, 12/11/26 dates
```

Replace each hit with generated content; run it again until clean.

## Last step: make things make sense

Read the screens as a Malaysian user: names, places and prices feel local and plausible together (a RM4,500 rent in Bangsar, not in Kepong for RM450), the same person keeps the same name everywhere, and nothing is a real public figure, real phone number in use, or real IC number. Report what was replaced.
