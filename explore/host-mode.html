Host mode: where to switch, and how you know you're hosting

Lokali-wide suggestion (Q13: one account, two modes; not in the brief). Story used here: Aina's host application is approved, so she can host and still book trips. Red outline = recommended.

1 · Where an approved host switches to hosting

Hosts open the app mostly to check bookings, so the switch should be one tap from where the app opens. The app also reopens in the last mode used (no UI needed).

A · Account tab only (today)

Switch to hosting sits in Account. Two taps, out of sight on Home; a new booking never reaches a host who is browsing trips.

2 · How she knows she is hosting

Host mode already has its own tab bar (Today, Calendar, Listings, Inbox, Menu). The question is whether that's enough when guest and host Inbox look alike.

1 · Tab bar only (today)

Different tabs are the only cue. Fine on Today, but Inbox and Chat look the same in both modes, so she can answer from the wrong side.

MIMS

  • Requirements: none of this is in the brief; it extends suggestion Q13 (one account, two modes). Mark it as a suggestion.
  • Recommend B + 2 + 3: one switch pill in the same top-right corner in both modes, a short switch moment, and "Hosting" on Today. Keep the Account and Menu rows as the second way in.
  • Cut: C (it only appears sometimes and pushes Featured down); a different tab-bar colour for hosting (colour alone fails accessibility, and red already means actions).
  • Story decision: today the guest is Aina and the host is Pak Rahim, so "switch" would jump to another person. Either Aina becomes the host after approval (her name and photo on host screens), or the switch is shown from Pak Rahim's side (he also books trips). Your call.
